## 0. 요약 (리포트 초록 초안)

**질문.** 시계열 파운데이션 모델 Kronos-base의 잠재 공간(residual stream)에서 "추세 없는 OHLCV"와 "선형 상승 추세를 가진 OHLCV"가 선형으로 구분되는가. 구분된다면 두 클래스의 활성화 차이로 만든 steering vector를 더해 예측을 바꿀 수 있는가. 그 결과로 모델이 이 개념을 예측에 인과적으로 쓴다고 말할 수 있는가.

**방법.** Wiliński et al. (ICML 2025)의 선형 프로브·LDR·steering 방법을 Kronos-base에 옮기고, 논문에 없는 대조군 다섯 가지(라벨 셔플 null, 입력 기준선, 무작위 초기화 모델, 랜덤 방향 개입, 역방향 개입)와 목표 분포(REF, 실제 추세 입력의 무개입 예측)를 더했다. 판정 규칙은 실행 전에 고정했다.

**결과 한눈에 보기** [사전]

| | OU (주 데이터) | RW (강건성) |
|---|---|---|
| held-out LDR (layer 11, t=511) | 23.53 | 15.74 |
| 라벨 셔플 null 대비 | 988배 | 631배 |
| 사전학습 / 무작위 초기화(Kronos 방식) | 0.98 | 1.54 |
| 사전학습 / 입력 기준선 | 1.69 | 9.31 |
| A 팔 양의 기울기 비율 (λ_rel 0.1 / 0.15 / 0.25 / 0.5) | 60.9 / 82.8 / 100 / 100% | 85.9 / 84.4 / 84.4 / 85.9% |
| 랜덤 방향 J 평균 (λ_rel 0.25) | 49.5% | 45.8% |
| 역방향 L 음의 기울기 비율 최대 | 76.6% | 60.9% |
| REF 양의 기울기 비율 | 0/64 | 32/64 |
| 표현 판정 문장 (outline §8.1) | 분리는 입력·구조에서 오며, 학습된 표현이라는 근거 없음 | 같음 |
| 개입 판정 (spec §2.2) | `direction_specific`, `reversible` 아님, `ref_match` 아님 | `no_effect`, `reversible` 아님 |

**결론 (허용된 세 종류의 문장으로).**

1. 선형 표현의 존재: 두 클래스를 가르는 선형 방향은 두 데이터 모두에 있다. 그러나 같은 구조의 무작위 가중치 모델도 비슷한 분리도를 보여, 이 분리가 사전학습의 산물이라는 근거는 얻지 못했다.
2. 개입의 출력 효과: 클래스 차이 방향(S) 개입은 OU에서 예측 기울기의 부호를 방향 특이적으로 양(+)에 모은다(64/64, 랜덤 방향은 49.5%). RW에서는 84~86%로 사전 기준 90%에 못 미친다. 부호를 뒤집은 개입은 두 데이터 모두 기준에 못 미친다.
3. 자연 행동과의 일치: 조정된 출력은 실제 추세 입력에 대한 모델의 예측과 다르다(OU에서는 두 분포가 완전히 갈리고 부호도 반대).

따라서 1차 실험의 가설("steering이 작동하면 모델이 그 개념을 기저 기작으로 쓴다")을 지지하는 증거는 얻지 못했다.

**사후 분석의 요지** [사후]. (i) 개입의 주된 효과는 평균 이동이 아니라 입력에 대한 예측 반응의 압축이다(λ_rel 0.25~0.5에서 표준편차가 1/14~1/19). (ii) S는 표현에서 분산이 가장 큰 방향, 곧 입력의 마지막 가격 수준을 따라가는 방향에 놓여 있고(layer 11에서 분산의 39~56%), 프로브가 찾은 판별 축과는 직교에 가깝다(cos 0.02~0.04). (iii) RW에서 음수로 남는 9~10개는 마지막 가격 수준이 가장 높은 입력이다.

**제목 후보**
- Kronos-base는 "추세"를 선형 표현으로 갖고 예측에 쓰는가 — MOMENT Steering 방법론의 금융 TSFM 적용과 대조 실험
- 읽히는 방향과 움직이는 방향은 다르다 — Kronos-base의 추세 표현 probing과 steering

## 1. 주제

이 절의 역할: 무엇을 묻는 연구인지, 대상과 방법의 출처, 용어, 결론을 쓰는 규칙을 고정한다.

### 1.1 연구 질문

- 원 질문 두 가지 (1차 실험 설계 `0812 _1차실험_전체설계.md`)

  2. 인과: 존재한다면 각 층의 hidden representation에 steering vector S_i를 더하는 개입만으로, 추가 학습 없이 예측을 추세 방향으로 바꿀 수 있는가.
- 재실험(v2 fast track)에서 구체화한 질문 다섯 가지 (`docs/spec.md` §0)

| ID | 질문 | 판정 재료 |
|---|---|---|
| Q0 | 1차(Colab) OU 결과가 재현되는가 | 1차 기준값 vs v2 실측 |

### 1.2 대상 모델: Kronos-base

- K-line(OHLCVA) 전용 decoder-only TSFM. 12층, d_model 832, d_ff 2048, 16 heads, max_context 512, 102.3M 파라미터 (Stage 0 실측, `logs/00_stage0.log`).
- 토크나이저: Transformer 오토인코더 + BSQ. 한 봉을 coarse/fine 서브토큰(각 10비트)으로 양자화하고 한 시퀀스 위치로 융합한다. 3.96M 파라미터.
- 전처리: 채널별 z-score 후 [−5, 5] clip. 위치 정보는 RoPE만 쓴다.
- 고정 revision: 모델 `2b554741…`, 토크나이저 `0e011738…`.
- 논문이 다룬 MOMENT(encoder-only, patch), Chronos(encoder-decoder, 이산 토큰), Moirai와 달리 금융 전용, 이산 토큰, decoder-only 자기회귀라는 점을 대비해 쓴다.

### 1.3 방법론 원전과 이 프로젝트가 가져온 것

- 논문: Wiliński et al., *Exploring Representations and Interventions in Time Series Foundation Models*, ICML 2025 (arXiv:2409.12915v5). 저장소의 `representations-in-tsfms/`에 PDF와 공식 구현(steertool)이 있다.
- 가져온 것 (논문 3.2~3.3절, 부록 A·D)
  - 합성 데이터로 두 클래스를 만든다. 논문의 "constant case"(m=0)와 "increasing slope case"(m>0)가 이 프로젝트의 base / trend에 대응한다.
  - 각 층·토큰의 residual stream(FFN 뒤)에서 Fisher criterion으로 선형 프로브를 학습하고 LDR로 분리도를 잰다. min-max로 스케일한 LDR 히트맵(논문 Fig. 7, 14)으로 위치를 본다.
  - steering 행렬 S_i = median(목표 클래스 활성화) − median(기준 클래스 활성화), 층마다 토큰×차원 행렬. 추론 때 h_i ← h_i + λS_i.
  - 논문의 보고: median과 mean은 차이가 없다. 단일 토큰 개입은 실패하고 전 토큰 개입이 필요하다. Chronos는 λ≈0.1, MOMENT는 λ=1. −λS는 방향을 뒤집는다(부록 D). PCA에서 조정된 표본이 목표 클래스 근처로 이동한다(Fig. 11).
- 논문이 보고하지 않은 것 (이 프로젝트가 더한 것). 논문의 steering 평가는 예시 그림과 PCA 이동 중심이다. 다음 비교는 본문과 부록에 없다.
  - 라벨을 섞은 null, held-out 분리
  - 입력 자체의 분리도, 학습되지 않은 모델의 분리도
  - 같은 크기의 임의 방향 개입
  - 실제로 그 개념을 가진 입력에 대한 모델의 무개입 출력(목표 분포)과의 비교
- 이 연구의 범위 밖: 논문의 표현 유사도(CKA)와 pruning 부분.

### 1.4 용어와 표기

| 용어 | 정의 |
|---|---|
| h_i^(t) | i번째 Transformer block 출력(FFN 뒤 residual stream), 층 i, 토큰 위치 t. `model.transformer[i]` forward hook 출력 |
| base / trend | 추세 없음 / 선형 상승 추세. 같은 표본 번호는 같은 노이즈 실현치를 공유하고 drift 항만 다르다 |
| OU / RW | 노이즈 과정. OU(평균회귀, θ=0.01)가 주 데이터, RW(랜덤워크)는 강건성 확인용 |
| LDR | Fisher 판별비. LDA 방향에 투영한 값의 (클래스 평균 차)² ÷ (클래스내 분산 합). held-out 값만 보고한다 |
| null | 라벨을 섞어 같은 절차로 잰 LDR |
| S | steering 행렬. 층 i, 위치 t마다 trend 중앙값 − base 중앙값. 대표 벡터는 late 구간(마지막 1/16) 평균 |
| λ_rel | 상대 강도 λ_i‖S_i‖/‖h_i‖. 층별 절대 λ_i는 여기서 역산한다 |
| 팔(arm) | 개입 조건. A = 논문 방법(median × matrix × 전 토큰 × 12층), J = 같은 노름의 랜덤 방향(seed 0~2), L = −λS, REF = trend 입력의 무개입 예측 |
| 양의 기울기 비율 | 예측 64스텝의 정규화 close에 대한 OLS 기울기가 양수인 입력의 비율. 0.5에 대한 양측 이항검정 |
| 분산비 | 코드와 요약표의 이름. 실제로는 기울기 표준편차의 비(개입 후 / 기준선) |
| λ* | A 팔이 양의 비율 ≥ 0.9, p < 0.01을 만족하는 최소 λ_rel |
| subset32 | 평가 입력 64개 중 앞 32개. 1차 실험과 입력·배치·seed가 같다 |

### 1.5 결론을 쓰는 규칙 (`docs/outline.md` §8)

- 말할 수 있는 것은 세 가지다. (a) 선형 표현의 존재, (b) 그 방향 개입의 출력 효과, (c) 그 효과와 모델 자연 행동의 일치 여부.
- "모델이 개념을 이해한다/이해하지 못한다"는 표현은 쓰지 않는다.
- 결론 문장은 실행 전에 만들어 둔 표에서 고른다. 판정 규칙은 결과를 본 뒤 바꾸지 않는다.

## 2. 계기

이 절의 역할: 왜 이 질문을, 왜 이 모델에, 왜 두 번 실험했는지 설명한다.

### 2.1 논문이 열어 둔 질문

- 논문은 MOMENT, Chronos, Moirai에서 "개념이 선형으로 분리되고, 클래스 차이를 더하면 출력이 그 개념 쪽으로 바뀐다"고 보고한다. 금융 K-line 전용 모델에서는 확인된 적이 없다.
- 가격 예측에서 추세(모멘텀)는 가장 기본적인 사전 개념이고, 논문의 "constant → increasing trend" 실험(Fig. 8 (iii), Fig. 11 (ii), Fig. 14 (ii))과 일대일로 대응한다.
- Kronos는 구조가 다르다. decoder-only라 마지막 토큰이 다음 예측의 출력 경로이고, 생성은 자기회귀이며, 토큰은 이산이다. 논문의 관찰(예: 단일 토큰 개입 실패)이 그대로 옮겨지는지 자체가 질문이다.

### 2.2 1차 실험(0812)의 목표와 그것이 남긴 것

- 1차의 목표 문장: steering이 작동함을 보여 "Kronos가 가격 예측 시 해당 개념을 기저 기작으로 활용하고 있음을 증명한다".
- 1차가 얻은 것 (3.5절에 수치)
  - 선형 방향은 존재한다(held-out LDR 23.76, null 대비 987배).
  - 논문 방법으로 예측 기울기를 양수로 모을 수 있다(λ_rel 0.25에서 32/32).
  - 그러나 실제 추세 입력에 대해 모델은 추세를 외삽하지 않았고(OU 0/32, RW 53.1%), 조정된 출력은 그 분포와 닮지 않았다.
- 1차가 풀지 못한 것 (재실험의 직접 계기)
  1. 완결되지 않음: RW 데이터의 개입 팔을 실행하지 못했다. 1차 문서가 "RW 개입 팔이 확정의 관건"이라고 적었다.
  2. 방향 특이성 미검증: 개입은 기울기 분포를 붕괴시켜(표준편차 0.023 → 0.001) "전부 작은 양수"로 만들었다. 같은 크기의 임의 섭동도 그럴 수 있는데 대조군이 없었다.
  3. 표현이 학습된 것인지 미검증: OU는 입력단 LDR(19.57)과 층 LDR(약 23.5)이 비슷하다. RW는 2.22에서 약 15로 커지지만 입력단은 1차원 통계, 층은 832차원 LDA라 직접 비교가 안 된다.
  4. 재현성: Colab 세션과 Drive에 의존해 로그와 중간 산출물을 다시 확인하기 어려웠다. 실행 도중 GPU를 T4에서 L4로 바꿨고 기준선 양의 비율이 59.4%와 46.9%로 갈렸다.

### 2.3 재실험(v2)의 목적

- 재현: 같은 코드, 같은 시드로 1차 핵심 수치를 다시 낸다.
- 완결: RW의 개입 팔을 실행한다.
- 보강: 랜덤 방향, 역방향, 무작위 초기화, 입력 기준선 대조군을 더해 인과 해석의 범위를 정한다.
- 가장 빨리 결론을 내는 부분만 골라 pod 1대, 실행 1회로 묶었다(fast track). 나머지는 Tier 2로 미뤘다.

### 2.4 [작성자 보완] 개인적 계기

- 저장소 문서에는 개인적 동기가 적혀 있지 않아 비워 둔다. 예: Kronos를 투자 예측에 쓰던 프로젝트(`Kronos-investing`)와의 관계, 해석 가능성에 관심을 갖게 된 경위.

### 3.2 논문 방법을 Kronos에 옮기며 정한 것

- 관측 지점: `model.transformer[i]` forward hook 출력. 논문과 같은 FFN 뒤 residual stream이다. 모델 개조가 필요 없다. 형태는 [L=12, N, T=512, D=832].
- probing은 자기회귀 생성이 아니라 컨텍스트 1회 forward(`decode_s1`)의 활성화로 한다.
- Fisher criterion은 LDA 닫힌 해로 푼다. `w = (Σ_w + εI)^-1 (μ_s − μ_c)`, LDR은 w에 투영한 값으로 계산한다. 공식 구현과 수치를 대조했고 차이는 분산 분모 관례(ddof) 하나였다. ddof=0으로 맞췄다. 층×위치 6144개 프로브를 GPU 배치 연산으로 처리한다.
- 논문에 없는 통제를 처음부터 넣었다: train 1434 / held-out 614 분할, 라벨 셔플 null, trace 기준 상대 shrinkage 1e-3 (train/d_model = 1.72).
- S는 논문대로 위치별 행렬(median)을 쓴다. 대표 벡터의 집계 구간은 late다. 토큰 평균은 초반 위치의 가격 수준 오프셋에 오염된다(cos 0.12).
- 개입은 12개 층 전부, 모든 위치에 한다. 생성 중에는 매 디코딩 스텝 hook이 발화한다. 컨텍스트 길이가 max_context와 같아 첫 스텝부터 창이 한 칸씩 밀리므로, 창 위치를 원래 인덱스에 맞추고 새로 생성된 토큰에는 S의 마지막 행을 쓴다.
- 강도는 상대값 λ_rel로 지정한다. 활성화 노름이 층에 따라 7.7배 변해 절대 λ를 전 층에 똑같이 쓰면 의미가 달라진다.
- 평가는 정규화 공간의 예측 close 기울기로 한다. OHLC coherence는 역정규화한 뒤에 본다. Kronos는 채널별로 따로 정규화하므로 정규화 공간에서는 L ≤ O, C ≤ H 순서가 보존되지 않는다.
- Kronos는 sample_count개(5) 샘플 경로를 평균해 반환한다. 샘플링은 temperature 1.0, top_p 0.9.
- 판정 통계는 결과 기울기 부호의 이항검정이다. 기준선과의 대응표본 비교가 아닌 이유는 5.6절에서 수치로 보인다.

### 3.3 합성 데이터

- 생성: 미세 격자(봉당 15스텝, 총 7680스텝) 위의 경로를 봉 단위로 집계해 OHLC를 만든다. coherence 제약이 정의상 충족된다. base는 `b + W(τ)`, trend는 `b + m·τ + W(τ)`이고 같은 표본 번호가 같은 W를 공유한다.
- 고정값: T 512, sigma 0.01, OU θ 0.01, 클래스당 2048표본, seed 20250812, V/A = 0, 두 클래스 timestamp 동일.
- drift는 SNR로 지정한다. snr ~ U(3, 6), 총 drift = snr × 노이즈 크기. z-score가 스케일을 없애므로 모델이 보는 것은 이 비율뿐이다.
- 결정과 근거
  - 로그가격에 exp를 취하지 않는다. 선형 drift가 지수 추세가 되는 것을 피한다.
  - OU가 주 데이터다. RW는 base 표본 상당수가 우연한 추세를 가져 라벨이 흐려지고, 입력단 LDR이 snr을 아무리 키워도 약 1.9에서 포화한다(1차 실측).
  - V/A = 0. Kronos가 학습 때 5% 확률로 V/A를 0으로 가렸으므로 표현이 무너지지 않는다.
- 1차에서 찾은 생성 결함: OU를 0에서 시작하면 모든 표본이 같은 점에서 출발해 첫 토큰의 분리도가 가장 높게 나온다. burn-in으로 고쳤다.

### 3.6 재실험(fast track) 설계

- 1차와 같게 둔 것: 데이터 생성, S 산출, 평가 절차, 샘플링 설정. 비교 가능성을 위해서다.
- 바꾼 것: 평가 입력 32 → 64개. 32개씩 두 번 생성하고 k번째 묶음의 seed는 seed + k다. 앞 32개는 1차와 입력·배치·seed가 같다.
- 고정값: 모델·토크나이저 revision 핀, float32 추론, TF32 off, RTX 4090 한 종류, λ_rel ∈ {0, 0.1, 0.15, 0.25, 0.5}.
- 팔

| 팔 | 입력 | 더하는 것 |
|---|---|---|
| `A_paper_median_matrix_all` | base held-out 64개 | λ_i · S (median, 위치별 행렬), 전 토큰, 12층 |
| `J_ctrl_random_s0`, `_s1`, `_s2` | 같음 | 층·위치마다 S와 같은 L2 노름의 가우시안 방향. 층, 범위, λ_i는 A와 같다 |
| `L_ctrl_reverse` | 같음 | −λ_i · S |
| `REF_trend_unsteered` | trend held-out 64개 | 없음 |

- 표현 대조군 (17개 위치 0, 32, …, 480, 511에서 같은 LDA·held-out·null 절차)
  - 입력 기준선: 위치 t까지의 정규화 close 경로(차원 t+1)
  - 무작위 초기화 Kronos-base: 구조와 사전학습 토크나이저는 그대로 두고 트랜스포머 가중치만 초기화
  - 사전학습 모델
- 사전 고정 판정 규칙 (`docs/spec.md` §2.2)

| 판정 | 조건 |
|---|---|
| `A_up` | A가 어떤 λ>0에서 양의 기울기 비율 ≥ 0.9 이고 p < 0.01. 최소 λ가 λ* |
| `direction_specific` | `A_up`이고 λ*에서 J 세 seed의 양의 비율 평균이 [0.3, 0.7] 안 |
| `generic_perturbation` | `A_up`이고 λ*에서 J 평균 ≥ 0.9 |
| `no_effect` | `A_up` 아님 |
| `collapse_generic` | λ*에서 J의 분산비 평균 ≤ 0.2 |
| `reversible` | L이 어떤 λ>0에서 음의 기울기 비율 ≥ 0.9 이고 p < 0.01 |
| `ref_match` | λ*에서 A 기울기 분포 vs REF의 KS p ≥ 0.05 |

- 표현 문장 선택 규칙: 마지막 층·t=511의 LDR 비율로 고른다. 비율이 [0.5, 2] 안이면 "비슷"으로 본다. 이 임계 2는 근거가 있는 값이 아니라고 명세에 적어 두었으므로 리포트에서도 비율 자체를 함께 보인다.

### 3.7 대조군 설계 결정: 무작위 초기화를 어떻게 할 것인가

- 문제: PyTorch 기본 초기화(`reset_parameters()`)는 임베딩이 N(0, 1)이라 Kronos 자체 초기화보다 약 29배 크다. 블록 출력이 residual에 거의 더해지지 않는다.
- 실측
  - 로컬(base 구조): 층당 블록 기여가 사전학습 0.21~0.39, Kronos 초기화 0.32~0.49, torch 기본 0.009~0.010. torch 기본에서 마지막 층 출력과 입력 임베딩의 코사인은 0.999.
  - 본 실행 로그: 활성화 평균 절댓값이 torch 기본에서는 layer 0 / 6 / 11이 13.445 / 13.445 / 13.453으로 변하지 않는다. Kronos 초기화는 1.026 / 1.681 / 2.229, 사전학습은 6.637 / 22.141 / 46.969다.
- 결정 (2026-10-05, 본 실행 전): 두 방식을 모두 돌린다. 판정에는 Kronos 자체 초기화(`_init_weights`: Linear는 xavier normal, Embedding은 std = d_model^-0.5)만 쓰고 torch 기본은 참고 열로 둔다. torch 기본은 "학습되지 않은 트랜스포머"보다 "위치별 토큰 임베딩"에 가까운 대조군이기 때문이다.
- 이 결정이 결론을 좌우한다는 점을 리포트에 명시한다(5.4절).

- λ_rel 0.5에서 J의 분산비 평균은 0.239로 임계 0.2 바로 위다. 붕괴는 정도의 차이다.
- 같은 노름에서 S 축은 훨씬 강하고(λ_rel 0.1에서 이미 0.091), 부호가 모이는 것은 S에서만이다.

**(4) seed에 따라 다르다** [사후]

- OU J seed 1: λ_rel 0.5에서 20/64 양수(양측 p = 0.0037). 양의 비율이 λ에 따라 53 → 52 → 42 → 31%로 내려간다.
- λ*에서 seed별 평균 기울기는 −0.0004 / −0.0049 / −0.0018이다. seed 1의 평균 이동 크기(−0.0040)는 A의 평균 이동(+0.0044)과 비슷하지만 표준편차가 0.0145라 부호가 모이지 않는다.
- RW J seed 1: 같은 입력끼리 비교하면 λ_rel 0.1~0.25에서 기준선보다 낮아진 입력이 45~47개(64개 중, Wilcoxon p = 0.007 ~ 0.0003)다. 양의 비율로는 39~44%라 부호 검정에서는 유의하지 않다.
- J 검정이 노이즈당 12개이므로 p < 0.01 하나는 우연으로도 나올 수 있다. seed 3개로는 랜덤 방향의 분포를 말하기 어렵다.

**(5) 프로브 축 이동량은 출력 효과를 예측하지 못한다** [사후]

- J의 LDA 축 이동량은 λ*에서 OU 0.36~0.95σ(A는 2.23σ), RW에서는 −1.28 ~ +0.81σ(A는 +1.33σ)다. RW seed 1은 A와 크기가 같고 부호가 반대인데 출력의 부호는 모이지 않는다.
- 이유: S의 LDA 축 성분(cos 0.040, 0.022)이 임의 방향의 기대 성분(0.028)과 같은 크기라, 같은 노름의 랜덤 벡터도 LDA 축으로는 S만큼 움직인다.
- 1차의 G, H 팔(LDA 방향 개입이 무효)과 같은 결론이다. 프로브가 읽는 축을 움직이는 것과 출력을 움직이는 것은 다르다.

### 5.8 분석 7 — 부호를 뒤집으면 (L 팔)

**(1) 판정** [사전]: 음의 기울기 비율이 OU 53.1 → 51.6 → 65.6 → 76.6%, RW 56.2 → 57.8 → 59.4 → 60.9%. 어느 λ에서도 90%에 못 미쳐 `reversible` 아님. OU의 λ_rel 0.5는 유의하지만(p = 2.4e-05) 비율 조건을 못 채운다.

**(2) −S도 분포를 압축한다** [사전 수치]: OU에서 L의 표준편차 비 0.138 → 0.111. 붕괴는 S 축의 양쪽 부호에 공통이다.

**(3) +S와 −S는 서로 갈린다** [사후]

| A > L인 입력 수 (64개 중, Wilcoxon p) | λ_rel 0.1 | 0.15 | 0.25 | 0.5 |
|---|---|---|---|---|
| OU | 32 (0.77) | 47 (6.6e-06) | 63 (4.5e-12) | 64 (3.5e-12) |
| RW | 39 (0.12) | 39 (2.3e-03) | 51 (3.1e-08) | 56 (3.5e-10) |

**(4) 대칭은 아니다** [사후, OU]

- 부호와 무관한 성분 (A+L)/2: +0.0003, +0.0010, +0.0011, +0.0011.
- 부호를 따르는 성분 (A−L)/2: 0.0001, 0.0009, 0.0025, 0.0034.
- λ_rel 0.5에서 +S의 오프셋은 +0.0045(자기 표준편차의 3.6배), −S의 오프셋은 −0.0023(0.85배)이다. −S에서는 입력 반응이 덜 줄어든다(z_T 회귀계수의 압축이 8~9배, +S는 21~33배). 평균이 표준편차의 0.85배만큼 음수 쪽에 있을 때 정규 근사로 기대되는 음의 비율은 80%이고 관측은 76.6%다.

**(5) 읽은 것**

- 논문 부록 D의 "−λS는 방향을 뒤집으며 대칭적"이라는 진술은 Kronos에서 부분적으로만 성립한다. 평균의 이동 방향은 +S와 반대로 가지만 크기가 대칭이 아니고 사전 기준을 채우지 못한다.
- 붕괴(부호와 무관)와 오프셋(부호를 따름)을 나눠서 보고한다.

### 5.9 분석 8 — 모델의 자연 행동과 닮았는가 (REF)

**(1) OU** [사전]

- 실제 trend 입력에 대한 무개입 예측은 64개 모두 하락이다. 평균 −0.0643, 범위 [−0.094, −0.028], 64스텝 동안 −3.16 (z-score 단위).

**(2) RW** [사전]

- REF는 32/64 양수, 평균 −0.0080, 중앙값 −0.0002. 음의 꼬리가 길다(왜도 −1.64, 최솟값 −0.072).
- A 대 REF의 KS p는 4.1e-05(λ_rel 0.1, 0.15)와 1.7e-05(0.25, 0.5)다. λ*가 없어 `ref_match`는 판정하지 않았다.

**(3) 모델의 자연 행동은 수준 되돌림이다** [사후]

**(4) 다른 팔도 REF와 닮지 않았다** [사후]: OU는 모든 팔에서 KS p ≤ 1e-24. RW에서 가장 덜 다른 것은 역방향 L(λ_rel ≥ 0.15에서 p = 0.02 ~ 0.04)이고 사전 기준 0.05에 못 미친다.

**(5) 읽은 것**

- (c) "효과와 자연 행동의 일치"는 두 데이터 모두에서 성립하지 않는다. OU에서는 부호까지 반대다.
- S를 더하면 표현은 trend 쪽으로 이동하지만(OU의 도달 비율이 λ_rel 0.25에서 0.48~0.64, 0.5에서 0.96~1.28), 출력은 실제 trend 입력의 출력 쪽으로 가지 않는다.
- [가설] 1차는 OU REF의 강한 하락을 "매끈한 램프가 학습 분포 밖이라 생긴 인공물"로 해석했다. v2는 이 해석을 검증하지 않았다. 저SNR OU로 확인할 수 있다.

### 5.10 분석 9 — RW에서 왜 85%에서 멈추는가 (Q4)

**(1) 판정** [사전]: A의 양의 비율이 85.9 / 84.4 / 84.4 / 85.9%이고 p는 3.5e-09 ~ 2.0e-08이다. 유의성은 채우지만 비율 조건(≥ 0.9)을 못 채워 `A_up`이 거짓, `no_effect`다. 규칙은 그대로 둔다.

**(2) 두 판정 체계가 여기서 엇갈린다**: `stage6`의 1차식 판정(유의성만 봄)은 RW의 A를 "상향 조정 성공"으로 분류하고, 사전 고정 판정은 `no_effect`로 분류한다. 공식 판정은 후자다. 리포트에 둘을 함께 보이고 차이가 기준(90%)에서 온다고 적는다.

**(3) λ_rel 0.1에서 이미 포화다** [사후]

- 평균 0.0039 → 0.0034, 표준편차 0.0031 → 0.0028로 거의 변하지 않는다. 평균 ÷ 표준편차가 1.21~1.26이고 여기서 정규 근사 양의 비율은 0.89다.
- λ_rel 0.5의 기울기가 0.1보다 큰 입력은 14개뿐이다. 세기가 모자라서가 아니다. 격자에 0.1 미만이 없어 효과가 시작되는 지점은 보지 못했다.

**(4) 음수로 남는 것은 늘 같은 입력이다** [사후]: 네 λ 모두에서 음수인 입력이 8개, 한 번이라도 음수인 입력이 11개다. λ 간 순위상관은 0.82 ~ 0.98이다.

**(5) 그 입력은 마지막 수준이 가장 높은 입력이다** [사후]

- λ_rel 0.25에서 음수인 10개의 z_T는 1.84 ~ 3.45(평균 +2.29)이고 나머지 54개의 평균은 −0.26이다(Mann-Whitney p = 6e-07).
- 이 10개는 기준선에서도 기울기가 낮았던 입력이다. 9개가 64개 중 하위 11위 안이고 나머지 하나는 20위다. 기준선 기울기 평균은 −0.058이다.

**(6) OU와 같은 기제로 설명된다** [사후]

- RW 기준선의 z_T 회귀계수는 −0.0253 (r = −0.93)이고 A에서는 −0.0015 ~ −0.0016으로 약 16배 작아진다. 오프셋은 +0.0035다.
- RW base 입력은 마지막 수준의 퍼짐이 크다(표준편차 1.52, 최대 3.45. OU는 1.04, 최대 1.80). 랜덤워크는 창 평균에서 멀리 끝나는 경우가 많다. z_T가 약 1.8 ~ 2.3을 넘으면 남은 되돌림 반응이 오프셋보다 커져 음수가 된다.
- OU에서는 같은 계산으로 남은 반응의 최대치(약 0.0014)가 오프셋(0.0036)보다 작아 전부 양수가 된다.

**(7) 읽은 것**

- RW의 `no_effect`는 "아무 변화가 없다"가 아니라 "사전 기준에 못 미친다"는 뜻이다. 분포는 크게 바뀐다(표준편차 비 0.07, 기준선과의 KS p = 3.6e-07).
- OU의 100%와 RW의 85%는 서로 다른 현상이 아니다. 같은 "압축 + 작은 양의 오프셋"이 입력 분포가 다른 두 데이터에서 다르게 집계된 것이다.
- 리포트에는 사전 판정과 이 기술을 구분해 나란히 적는다.

**(8) RW에서만 보이는 것** [사전 수치]

- L의 압축이 느리다(표준편차 비 0.396 → 0.136. A는 λ_rel 0.1에서 이미 0.075).
- OHLC coherence 위반: 기준선 0.02%, L 0.49 ~ 0.81%, J seed 2는 λ_rel 0.5에서 1.05%. REF는 개입이 없는데도 2.32%다. 위반은 개입만의 현상이 아니다.

### 5.11 분석 10 — 읽는 축과 움직이는 축

| | 프로브 축 (LDA 방향) | 조정 벡터 S |
|---|---|---|
| 만드는 법 | 클래스내 분산으로 백색화한 평균 차 | 클래스 중앙값의 차 |
| 담는 분산 (layer 11, t=511) | 0.014% | OU 56%, RW 39% (base만으로는 45%, 26%) |
| 그 축 위의 클래스 분리 (LDR, in-sample) | OU 30.4, RW 19.3 | OU 1.45, RW 2.76 |
| 따라가는 입력 특성 (OU base 내 상관) | 창 기울기 +0.56, 거칠기 −0.34, 수준 +0.11 | 수준 +0.93, 창 기울기 +0.10, 거칠기 −0.06 |
| 그 방향으로 밀었을 때의 출력 | 1차 G 팔: 변화 없음 (분산비 0.951) | 표준편차 1/14 ~ 1/19 (λ_rel 0.25~0.5), 부호 정렬 |

- "선형으로 잘 분리된다"와 "클래스 차이 방향으로 밀면 출력이 바뀐다"는 서로 다른 방향에 대한 진술이다.
- 논문의 흐름(프로브로 개념을 확인하고, 클래스 차이로 그 개념을 조정한다)을 Kronos에 옮기면 두 단계가 같은 것을 가리킨다는 보장이 없다. 프로브는 기울기와 거칠기를 읽고, steering은 수준 축을 민다.
- 데이터 설계의 교란: 창 단위 z-score 아래에서 "상승 추세"는 (i) 위치별 수준 오프셋과 (ii) 작아진 거칠기를 함께 만든다. 프로브와 S는 이 부산물을 각각 집어 간다. 이 설계로는 "추세 개념"만 따로 떼어 말할 수 없다.

**세 종류의 문장으로**

| | 근거 | 말할 수 있는 것 |
|---|---|---|
| (a) 선형 표현의 존재 | LDR 23.5 / 15.7, null 0.024. 무작위 초기화 대비 0.98 / 1.54 | 선형 분리 방향은 있다. 사전학습의 산물이라는 근거는 없다. RW는 일관된 차이가 있으나 기준 미달이다 |

| (c) 자연 행동과의 일치 | OU: REF 0/64, KS 완전 분리. RW: KS p ≈ 2e-05 | 일치하지 않는다 |

**원 질문에 대한 답**

- "구분되는가": 구분된다. 다만 OU에서는 같은 수준의 구분이 입력 통계와 무작위 가중치 모델에서도 얻어진다. RW에서는 사전학습 모델이 1.5~1.7배 높지만 사전 기준에 못 미친다.
- "steering vector로 예측을 바꿀 수 있는가": 바꿀 수 있다. OU에서는 방향 특이적이다. 바뀌는 방식은 예측을 기준선보다 위로 옮기는 것이 아니라, 입력에 대한 반응을 눌러 작은 양의 기울기로 모으는 것이다.
- "개념을 인과적으로 활용하는가": 이 설정에서는 그렇게 말할 증거를 얻지 못했다.
  - 사전 정의 문장으로는 OU가 "방향 특이적 조정은 가능하나, 모델이 실제 추세 입력에 하는 계산과 다른 출력을 주입", RW가 "해당 설정에서 인과적 사용의 증거 없음"이다.
  - 사후 분석이 덧붙이는 이유는 둘이다. S는 추세가 아니라 수준 축에 놓여 있다. 프로브가 읽는 방향을 움직여도 출력은 움직이지 않는다(1차의 G·H 팔에서 직접, v2에서는 J의 축 이동량으로 간접 확인).

**아직 모르는 것**

- 왜 +S가 작은 양의 기울기를 만드는가. 수준 축에서 "끝이 높은 입력"은 자연 상태에서 하락 예측과 연결되는데 개입 결과는 반대 부호다.
- RW의 1.5배 차이가 무작위 초기화 seed의 변동 안에 있는가.
- 조정된 예측의 형태가 지속적 상승인가, 한 번의 수준 이동인가.

### 6.1 한계

### 6.2 후속 과제

분석에서 새로 나온 것

1. 무작위 초기화 seed를 여러 개로 늘려 RW의 1.54배가 변동 안인지 본다.
2. 입력 기준선을 강화한다(기울기 + 거칠기 통계, OHLC 전체, 비선형 기준선).
3. 교란을 통제한 클래스 쌍을 만든다. 마지막 수준을 맞춘 쌍, 정규화 뒤 거칠기를 맞춘 쌍.
4. S를 분해해 개입한다. 수준 축 성분을 뺀 S, 수준 축 단독, S에 직교화한 랜덤 방향(K).
5. λ_rel 0.1 미만 격자를 더한다.
6. 예측 경로를 저장해 조정 전후 경로 그림을 만든다.
7. 사후 분석 스크립트를 저장소에 넣고 그림 네 장(4.6절)을 만든다.

설계에 이미 있던 것 (`docs/outline.md` §5의 Tier 2)

- trend 입력에 −λS를 더하는 M 팔, RW의 B~I 팔
- 평가 입력 128개 이상, 부트스트랩 신뢰구간, S 추정 안정성
- 샘플링 민감도(sample_count, temperature)
- 저SNR OU, V/A가 0이 아닌 변형
- (선택) 변동성 군집 같은 금융 stylized fact, 실데이터 probing

### C. 사후 분석의 계산 정의

1. 표본별 기울기: `steer/results.json`의 키 `<팔>|<λ>` 아래 `slopes`(길이 64). 입력 순서는 held-out 인덱스 `split_indices(2048, 0.3, 20250812)`의 앞 64개다.
2. 쌍별 비교: 같은 입력 인덱스끼리 팔 대 기준선, A 대 L을 비교한다. 큰 쪽의 개수, Wilcoxon signed-rank, Welch t.
3. 정규 근사: Φ(평균 ÷ 표준편차). 표준편차는 ddof=0.
4. 입력 특성: `data/v2/<noise>/{base,trend}.npz`의 `x`에 Kronos 전처리(채널별 z-score, ddof=0, ε=1e-5, clip ±5)를 적용한 close에서 계산한다. z_T는 마지막 값, 창 기울기는 OLS 기울기, 거칠기는 log 평균 |Δz|, 범위는 log 평균 (고가 − 저가) ÷ close 표준편차, 잔차 표준편차는 선형 적합 뒤의 값이다.
5. 수제 통계의 LDR: 위 특성의 1차원 LDR 또는 표준화 뒤 LDA(수축 1e-3). 파이프라인과 같은 train 1434 / test 614 분할, ddof=0.
6. 대조군 격자: `stage3_controls.json`의 `pretrained`, `random_init`, `random_init_torch`, `input` 아래 `ldr_test`끼리의 비.
7. S의 성격: `steering.npz["S_matrix_median"][i, 511]`, `ldr.npz["w_last"][i]`, `pca_subset.npz["act"]`(토큰 511, 클래스당 앞 512표본). 단위 벡터 투영, 두 클래스를 합친 활성화의 PC1과의 코사인, 그 방향의 분산 비중, 클래스내 상관. in-sample이다.
8. 위치 프로파일: cos(S_i^(t), S_i^(511))와 ‖S_i^(t)‖를 위치별 클래스 중앙값 수준 차이와 비교한다.
9. 수준 되돌림 회귀: 팔마다 `예측 기울기 = b0 + b1 · z_T`를 OLS로 맞춘다. "압축 배수"는 기준선 b1 ÷ 그 팔의 b1이다.

### D. 표기상 주의

- `data/v2/rw/meta.json`의 `data_cfg.noise_type`은 기본 설정값 "ou"가 찍힌 것이다. 실제 노이즈는 최상위 `noise_type: "rw"`이고 지문과 입력 LDR로 확인된다.
- 무작위 초기화 추출 로그의 "저장 형태 [L, N, T, D]"는 명목값(T=512)이다. 실제로는 17개 위치만 저장한다(클래스당 0.65GB).
- `fast_summary.md`의 Q0 표는 12개 층 값의 중앙값을 "정렬 후 7번째 값"(위쪽 중앙값)으로 낸다. 그래서 cos(mean, median) 0.9814, cos(LDA, median) 0.0438, 정점 위치 350으로 적힌다. 가운데 두 값의 평균으로 내면 0.9782, 0.0402, 349.5이고 앞의 둘은 1차 값과 같다(Stage 4 로그). 일치 판정은 어느 쪽으로도 같다. Stage 3 로그는 정점 위치를 349로 적는다.
- `stage6` 로그의 "3. 판정" 블록은 1차식 판정이다. "가장 적은 lambda 로 100%"는 고정 문구이며 RW의 실제 값은 85.9%다. 공식 판정은 "2a. fast 판정" 블록이다.
- 표준편차는 Stage 5 로그와 `results.json`이 ddof=0(예: 0.02415), `stage6` 2b 블록이 ddof=1(0.02434)이다.
- "분산비"는 표준편차의 비다.
- 개념축 이동(σ)은 payload를 LDA 축에 투영한 값을 클래스내 산포 단위로 잰 해석적 값이다. 측정한 활성화가 아니다.
- KS p = 8.35e-38은 표본 64 대 64에서 가능한 최솟값이다.
