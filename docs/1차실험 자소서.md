i.	시계열 예측 모델에 대해서 공부함
ii.	현재 시계열 예측 분야에서 두각을 드러내고 있는 TSFM이라는 분야에서 금융 ohlcva 데이터로 학습시킨 Kronos라는 모델에 대해 집중적으로 연구함.
iii.	이 모델의 구조를 이해하고 “nlp분야의 LLM 모델은 attention 매커니즘으로 특정 단어에 문맥상의 의미를 표현할 수 있도록 하는데, 같은 decode-only transformer 구조를 가진 Kronos가 입력으로 받은 ohlcva 시계열을 latent space에서 어떤 방식으로 이해하고 있을까” 에 대한 궁금증을 가지게 됨.
iv.	이 궁금증을 해결하기 위해 아래의 실험을 진행했습니다.
1.	Trend 라벨링 데이터 : [같은 노이즈를 가지되 Y = X+b 형태의 선형 증가하는 ohlc 합성 데이터] 
constant 라벨링 데이터 : [같은 노이즈를 가지되 Y = c 형태의 변화가 없는 ohlc 합성 데이터] 
를 생성함
2.	Trend 라벨링 데이터와 constant 라벨링 데이터를 Kronos에 입력에 넣고 한 라벨링 데이터에 대해 [decode-only 구조의 12개층의 residual stream]을 입력 데이터의 라벨링을 상속하여 저장한다.
3.	이 residual stream을 분류하도록 층마다 다른 12개의 linear probe를 학습시킨다. 이때 목적함수는 fisher criterion을 사용한다.
4.	학습시킨 선형 분류기는 두 라벨링 데이터를 잘 분류하도록 학습이 됨을 확인했다. Kronos가 두 데이터를 “다름”을 이해하고 있다는것을 확인했으니, 두 데이터의 “다름” 을 “선형 증가 와 변화없음”으로 이해하고 구분하는것인지 확인하는 실험을 시작한다.
5.	같은 노이즈를 공유하는 trend 라벨링 데이터와 constant 라벨링 데이터를 넣어서 만든 residual stream의 벡터 표현을 서로 뺀다. 빼서 만든 벡터 표현은 “선형증가”에 해당하는 모델의 벡터 표현이다. 이 벡터를 steering 벡터라고 칭한다. 
6.	이 steering 벡터가 순수하게 “선형증가”를 표현하는 벡터라면, 이 steering 벡터를 [B 노이즈를 가진 constant 라벨링 데이터를 넣어서 만든 residual stream]에 더한다면 [B노이즈를 가진 trend 라벨링 데이터를 넣어서 만든 residual stream]과 같을 것이다. 노이즈가 다르기에 당연히 같은 수는 없고 “선형증가”의 의미를 갖는 residual stream 일것이다. 이것을 실험자인 우리가 확인할 수 있는 방법은 이전에 학습시킨 linear probe에 통과 시켰을때 trend로 판단하는것을 확인하는것이다. 이 실험을 steering 실험이라 칭한다.
7.	이 steering 결과를 보았을때 선형분류기는 해당 residual stream을 여전히 constant로 분류했습니다.
8.	이 실험결과를 보았을때 Kronos 모델은 가장 단순한 금융의 개념인 선형증가를 이해하지 못하고 있다라는 결론을 내릴 수 있었습니다.  
v.	이 결과를 보고 nlp의 LLM에서는 가능했던 개념 이해가 왜 금융 도메인에서는 가능하지 않은것인가에 대한 고민을 깊게 하게 되었습니다. 
vi.	제가 내린 결론은 아래 두가지 입니다.
1.	TSFM은 Large pretrain 모델이고 large train 모델의 기본 특성인 “블랙박스” 특성상 내부의 계산 과정에서 설명가능성을 확보하는것이 어렵고 이는 신뢰성이 중요한 금융분야에는 치명적인 단점이다.
2.	금융 데이터로 학습 시키는 것 만으로 금융 법칙을 이해하는 모델을 만들 수 없다는 사실을 알게됨.
3.	게다가 금융 데이터는 데이터가 적은 도메인이기 때문에 nlp의 LLM처럼 큰 모델에게 많은 데이터로 스스로 법칙을 깨우치게하는 학습법은태초부터 성공할 수 없는 학습법임을 깨닫게 됨.
